# Glass Energy Systems — Motion System

## Current Rule

No motion will be implemented during the first visual-fidelity build.

Motion will only be added after:

1. Static desktop layouts are approved.
2. Tablet layouts are approved.
3. Mobile layouts are approved.
4. Section connector alignment is approved.
5. Accessibility and reduced-motion behavior are defined.

## Planned Motion

- Slow connector-line drawing
- Subtle node activation
- Minor glass-plane depth movement
- Soft section entrance transitions
- Sticky navigation surface transition
- Reduced-motion alternative

## Prohibited Motion

- Scroll hijacking
- Constant floating elements
- Large 3D rotations
- Particle effects
- Gaming-style glow effects
- Excessive parallax
- Cinematic zoom transitions
